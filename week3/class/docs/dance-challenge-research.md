# 인스타그램 댄스 챌린지 트렌드 리서치

- **조사일:** 2026-10-13
- **방법:** Playwright MCP로 인스타그램 검색 탭에서 `댄스챌린지` 키워드 검색 → 상위 게시물 30개 수집 → 2026년 게시물 17개의 작성자·날짜·캡션 확인
- **수치 기준:** 좋아요 수는 조사일 기준이며, 인스타그램 추천 순서 결과라 전체 인기 순위와는 다를 수 있음
- 썸네일을 누르면 해당 릴스로 이동합니다.

## 요약

- 지금 가장 활발한 건 **퇴사 챌린지**. 전소연(@i_dle_official) 관련 해시태그와 "요즘 이 릴스는 대유행중"이라는 언급이 있고, 좋아요도 17K로 가장 많음.
- **권루트 챌린지**(#l을가져가)와 **밤편지 챌린지**가 10월 들어 막 올라오는 중.
- 올해 좋아요가 가장 많은 건 2월의 **미워** 챌린지(38K).
