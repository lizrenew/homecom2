# 🥢 대패삼겹 숙주볶음 덮밥 (1인분, 약 10분)

![대패삼겹 숙주볶음 덮밥](images/daepae_sukju_bowl.png)

고기 기름에 숙주를 볶아 짭조름하게 간을 하는 덮밥입니다. 밥 한 공기는 금방 비워요.

## 재료
| 재료 | 분량 |
|---|---|
| 대패삼겹살 | 200g |
| 숙주 | 1줌 (약 150g) |
| 대파 | 1/2대 |
| 다진 마늘 | 1큰술 |
| 밥 | 1공기 |
| 계란 (선택) | 1개 |

**양념:** 간장 1.5큰술, 굴소스 1큰술(없으면 간장 0.5큰술 추가), 설탕 0.5큰술, 후추 약간, 참기름 약간

## 만드는 법
1. **준비 (1분):** 대파는 송송 썰고 숙주는 한 번 헹궈 물기를 빼 주세요. 양념 재료는 미리 섞어 둡니다.
2. **고기 굽기 (3분):** 달군 팬에 기름 없이 대패삼겹을 올려 노릇하게 굽습니다. 고기에서 기름이 나오니 기름을 따로 두르지 않아도 됩니다.
3. **향 내기 (1분):** 대파와 다진 마늘을 넣고 고기 기름에 볶아 향을 냅니다.
4. **양념 (1분):** 섞어 둔 양념을 팬 가장자리에 부어 살짝 끓인 뒤 고기와 버무립니다. 이렇게 하면 불맛이 납니다.
5. **숙주 (1분):** 센 불에서 숙주를 넣고 **30초~1분만** 빠르게 볶습니다. 오래 볶으면 물이 생기고 숨이 죽어요.
6. **마무리 (2분):** 불을 끄고 참기름을 한 바퀴 두른 뒤 밥 위에 올립니다. 계란 프라이를 반숙으로 얹으면 더 맛있어요.

## 💡 팁
- 매콤하게 먹고 싶다면 3번 단계에서 청양고추 1개나 고춧가루 0.5큰술을 넣으세요.
- 마지막에 깨를 뿌리면 고소한 맛이 더해집니다.
- 숙주가 없다면 양배추나 양파로 바꿔도 맛있습니다.

맛있게 드세요! 🍚
