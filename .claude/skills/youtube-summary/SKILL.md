# 유튜브 영상 요약 스킬

유튜브 URL 하나로 영상(선택) · 자막(srt) · 자막 마크다운 · 요약 마크다운을 한 폴더에 만든다.

## 저장 위치

- 사용자가 폴더를 지정하면 그곳에 저장한다.
- 지정하지 않으면 가장 최근 주차의 `weekN/class/` 폴더에 저장한다 (예: `week4/class/`). 어느 주차인지 애매하면 물어본다.
- 파일 이름 (`<짧은제목>`은 영상 제목에서 핵심 단어만 뽑아 띄어쓰기 없이, 예: `30대메이크업`)
  - 영상: yt-dlp 기본 이름 `<제목> [<영상ID>].mp4`
  - 자막: yt-dlp 기본 이름 `<제목> [<영상ID>].<언어>.srt`
  - 자막 마크다운: `<짧은제목>_자막.md`
  - 요약: `<짧은제목>_요약.md`
- 같은 이름의 md 파일이 이미 있으면 덮어쓰지 말고 먼저 물어본다.

## 절차

1. **요청 파악**: URL, 저장 폴더, 영상 파일까지 받을지 확인한다. 말하지 않았으면 영상도 받는다. 사용자가 "자막만", "요약만"이라고 하면 `-NoVideo`를 쓴다.

2. **다운로드**: `scripts/fetch.ps1` 실행. 자막은 업로더 자막 → 자동 자막 원본(`ko-orig`) → 자동 자막(`ko`) 순으로 자동 선택된다. 마지막 출력 줄이 srt 경로이고, `SUBKIND=` 줄이 자막 종류다.
   ```powershell
   & ".claude/skills/youtube-summary/scripts/fetch.ps1" -Url "<URL>" -OutDir "<저장폴더 절대경로>"
   # 자막만: -NoVideo 추가 / 영어 영상: -Lang en
   ```
   - 영상이 길면 수백 MB라 시간이 걸린다. `timeout`을 600000으로 준다.
   - 자막이 전혀 없다고 나오면 사용자에게 알리고 멈춘다.

3. **제목 확인**: 아래 명령으로 영상 제목을 정확히 가져온다 (터미널 출력은 한글이 깨지므로 파일 이름에서 읽는 편이 확실하다).
   ```powershell
   Get-ChildItem -LiteralPath "<저장폴더>" -Filter *.srt | Select-Object Name
   ```

4. **자막 마크다운 변환**: `scripts/srt2md.ps1` 실행. 중복 줄을 없애고 1분 단위 문단(`## [MM:00]`)으로 묶는다.
   ```powershell
   & ".claude/skills/youtube-summary/scripts/srt2md.ps1" -SrtPath "<srt 경로>" -OutPath "<저장폴더>\<짧은제목>_자막.md" -Title "<영상 제목>" -Url "<URL>" -SubKind "<SUBKIND 값>"
   ```

5. **요약 작성**: 자막 마크다운을 Read로 끝까지 읽고, 아래 템플릿으로 `<짧은제목>_요약.md`를 Write로 작성한다.
   - 자막 문장을 그대로 옮기지 말고 내 말로 정리한다.
   - 자동 자막의 오인식(제품명, 고유명사)은 문맥상 확실할 때만 고치고, 불확실하면 빼거나 일반 명칭으로 쓴다.
   - 영상 성격에 맞게 섹션을 고른다: 튜토리얼이면 단계별 팁, 강의면 개념 정리, 비교 내용이 있으면 표.

6. **보고**: 만든 파일들을 링크로 알려주고, 요약의 핵심을 2~3줄로 전한다.

## 요약 템플릿

```markdown
# <주제> 영상 요약

- 원본: [<영상 제목>](<URL>) (약 N분)
- 전체 자막: [<짧은제목>_자막.md](<짧은제목>_자막.md)

## 핵심 메시지

> **한 문장 핵심**
> 보충 한 줄

영상의 배경과 주장 2~4문장.

## <비교표 / 핵심 개념> (해당될 때만)

| 항목 | A | B |
|---|---|---|

## 단계별 내용 / 주요 포인트

### 1. <소주제>
- 포인트
- 포인트

## 정리

1. 결론 1
2. 결론 2
```

## 주의사항 (지난 작업에서 겪은 문제)

- **PATH**: winget으로 막 설치하면 현재 셸에서 `yt-dlp`를 못 찾는다. 스크립트가 PATH를 다시 읽으므로 스크립트를 쓰면 된다.
- **대괄호 경로**: 파일명에 `[영상ID]`가 들어가므로 PowerShell에서 `Move-Item`/`Get-Content`/`Remove-Item`은 반드시 `-LiteralPath`를 쓴다. 안 그러면 조용히 실패한다.
- **한글 깨짐**: PowerShell 5.1은 BOM 없는 UTF-8 스크립트의 한글을 깨뜨린다. 스크립트를 수정하면 UTF-8 **BOM 포함**으로 다시 저장한다. yt-dlp 터미널 출력의 한글이 깨져 보이는 것은 표시 문제일 뿐 파일명은 정상이다.
- **용량/git**: 영상(mp4)은 수백 MB라 GitHub 100MB 제한에 걸린다. 커밋하기 전에 사용자에게 `.gitignore` 추가 여부를 묻는다.
- **저작권**: 자막 마크다운은 원작자의 말을 그대로 옮긴 개인 참고용이다. 공개 저장소에 올리지 않도록 안내한다.
- **업데이트**: 다운로드가 갑자기 실패하면 먼저 `yt-dlp -U`로 업데이트한다.
